Data & API

Non-USD pegged stablecoins · 38 tokens · 19 fiat pegs · 7 chains · refreshed every 2 days

The full dataset behind the solosolver dashboard is public. No key, no signup. Free to use with attribution. If you are a journalist, researcher or developer, this page is for you.

Coverage

  • Networks: Polygon, Stellar, Solana, Tron, Plasma, BSC, Arc
  • Current tokens: 38 tokens across 19 fiat pegs, for example A7A5 (RUB), EURC (EUR), BRZ (BRL), AUD, TRYB (TRY), MXNB (MXN), ARS
  • Metrics: daily transfer count, daily transfer volume (USD)
  • Window: rolling 365 days (Plasma, BSC and Arc from their first tracked day), refreshed every 2 days

Schema

data.json is keyed by network. Each network holds newline-separated daily rows; each row starts with the date, followed by repeating token|transfer_count|volume_usd triplets for every token active that day: date|token|count|volume_usd|token|count|volume_usd|....

Quick start

import requests

raw = requests.get("https://analytics.solosolver.xyz/data.json").json()
rows = []
for network, block in raw["data"].items():
    for line in block.strip().splitlines():
        parts = line.split("|")
        date = parts[0]
        for i in range(1, len(parts) - 2, 3):
            rows.append((network, date, parts[i], int(parts[i + 1]), float(parts[i + 2])))

# total 365-day volume for the ruble token A7A5
a7a5 = sum(v for _, _, t, _, v in rows if t == "A7A5")
print(f"A7A5 365d volume: ${a7a5:,.0f}")
