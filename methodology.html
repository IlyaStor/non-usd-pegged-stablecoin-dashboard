Methodology

Solosolver is Ilia’s personal project on non-USD stablecoins, onchain FX, and payments infrastructure. This page describes the tracker as it is built in this repository. It does not add a number that the code does not compute.

Tracked volume and the registry

The charts, hero total, rankings, and shares read data.json. Each network is a pipe of date|token|tx_count|volume_usd. A token is tracked only when that symbol is in the pipe.

registry/verified-additions.json is a catalog of checked identities. A catalog row does not add a day or a volume. The Registry tab says so. data.json is not rewritten by the catalog.

Refresh

.github/workflows/refresh-data.yml runs on the cron 0 0 */2 * *, about every 2 days, and on manual dispatch. fetch-dune-data.js executes the query ids in lib/series.js, waits, and drops the incomplete UTC day of that execution. The page drops that same day. A completed result younger than 20 hours is reused. The default performance tier is medium. This page does not add a query to that schedule.

What counts as a transfer

  • Polygon 6614895 and 6621899: value > 0, sender is not the zero address, receiver is not the zero address or 0x…dEaD, and sender is not receiver. daily_transactions is distinct transaction hashes.
  • BSC 8748306: the same mint, burn, self-transfer, and zero-value exclusions. daily_transactions is distinct transaction hashes.
  • Plasma 6663259: the same mint, burn, and self-transfer exclusions, and value > 0. daily_transactions is COUNT(*), not distinct hashes.
  • Solana 6689171: rows in tokens_solana.transfers with amount_display > 0. That file does not apply the zero-address mint or burn filter. amount_display is already scaled. daily_transactions is COUNT(*).
  • Stellar 6712377: successful events whose first decoded topic symbol is transfer, for the listed contracts only. Classic Stellar payments (asset code plus issuer) are not in stellar.history_contract_events. The file does not apply a zero-address filter.
  • Arc 8924650: ERC-20 Transfer logs from 2026-09-16, excluding mint, burn, and self-transfers. Transactions that emit pool Mint, Burn, or Collect are excluded. The StableFX escrow address 0xe2e5f173576b513d994073ccbdacbe027d43dfe6 is excluded as a sender so the outbound leg of a settlement is not counted again.
  • Tron 6695880: the query id is executed by the refresh. Its SQL is not stored here, so this page does not describe its mint, burn, or self-transfer filters.

Pricing

Where a query joins prices.day, that price is used for the day. The numeric fallback in the query is used only when that join has no row. Those fallbacks are static literals in the SQL. They are not a live FX feed.

The static IDR fallback already used for XIDR, IDDR, and IDRT in sql/replacements/6621899_polygon.sql is 0.000061. IDRX uses that same static rate. Polygon part 1 writes Euro fallbacks as 1.04. lib/series.js FX_FALLBACK is a separate static table, used only when a result row has no transfer_volume_usd. Its Euro rate is 1.1206. The two tables are not the same number. Arc multiplies by the ECB reference rates of 2026-10-09 written in sql/replacements/8924650_arc.sql. Plasma uses only its own static fallbacks and does not join prices.day. Stellar multiplies by the static fx_usd on each token row.

BRMB is not emitted. There is no CNY rate in the Stellar query or in FX_FALLBACK. A 0 or 1 rate is not used.

A7A5

The published label is exactly A7A5. In the current data.json it appears on Tron only, query 6695880. The contract named for that series is 0x751f6515e355dc49474a8565a1234bf3424b9fe4. Its share of tracked volume is computed from data.json when this page loads: reading data.json…

The header control “Without A7A5” leaves the series unchanged until it is pressed. Pressed, the page drops points whose token label is exactly A7A5 from the hero total, charts, rankings, shares, and geography. The URL gains without=A7A5 so the view can be shared. The default has no such parameter, so A7A5 stays included. data.json is not edited.

Chains that are not in the refresh

Ethereum and Base are query 9117254. The SQL is sql/candidates/ethereum_base_tokens_transfers_365.sql, including Base IDRX at 2 decimals. One result carries a blockchain column, and the refresh splits it into data.ethereum and data.base. ETHEREUM_BASE_QUERY_ID is 9117254. The workflow still runs about every 2 days. Each refresh now executes this one extra query, about 25 credits for a full run, on top of the eight existing queries. The history run 01M77ZG014V1XZDMFAAMSQ52XQ returned 2,272 rows for 2025-11-12 through 2026-11-12. Those rows are not in data.json until a refresh fetches the id. The Ethereum and Base tabs are drawn only after that series is in the file.

Arbitrum, Optimism, Tempo, and XRPL stay in disabled candidate files. They are not on the refresh. Algorand, Xahau, and Adi Chain have no confirmed dataset page in this pass. That is not a claim Dune will never index them.

IDRX

IDRX is the rupiah token from PT IDRX Indo Inovasi, pegged 1 IDRX = 1 IDR, from the issuer list. It is not XIDR, IDDR, or IDRT. It is not in data.json yet. The parent saved it on the existing queries: Polygon 6614895 v24, BSC 8748306 v5, and Solana 6689171 v36. Base IDRX is in query 9117254. The next refresh is what writes the series. This repository does not run those queries.

  • Polygon 0x649a2DA7B28E0D54c13D5eFf95d3A660652742cC, decimals 0, saved on query 6614895 v24 only. Decimals stay 0. The raw value is not divided by 10^6 or 10^18.
  • BNB Chain, the same address, decimals 0, saved on query 8748306 v5.
  • Base 0x18Bc5bcC660cf2B9cE3cd51a404aFe1a0cBD3C22, decimals 2, in the Ethereum/Base candidate. tokens_evm.transfers.amount is already decimal-adjusted.
  • Solana mint idrxZcP8xiKkYk6XGD4uz1dxEYCWSgKDHqgjsBbwDur, decimals 2, saved on query 6689171 v36. amount_display is already scaled. The deprecated mint idrxTdNftk6tYedPv2M7tCFHBVCpk5rkiNRd8yUArhr is not added. That same version also lists ZARsc, mint 5ekaHEqpRUXH4RoZVRMErdJE74bibWAzihMtPcjKyceQ, decimals 6, Token-2022. ZARsc is already in the published Solana series. Its static fallback is 0.0604847, the same rate as ZARU.

There is no Ethereum IDRX row. Stellar, Tron, Plasma, and Arc have none. Celo, Monad, and Kaia are on the issuer list and are not on this tracker. No contract for those three is stored here.
